## 4. 幂等与执行方式

- 每块 `SET @g := (SELECT COUNT(*) FROM 表 WHERE id BETWEEN 520000000 AND 529999999)`，已存在则整块跳过；末尾附带管理层角色菜单复制（按 role_id 守卫）与银行账户余额回写（按流水守卫）。

- 主库 `erp_db` 已执行（后端 8080 无需重启，实时可见）；若后端未来经 Flyway 重启会再次触达本脚本，幂等守卫直接跳过。

## 5. 一致性自检（隔离库与主库双重复核，均为 0 违例）

| 检查项 | SQL 语义 | 结果 |
|---|---|---|
| 库存守恒 | `inv_stock.qty = Σ inv_movement.qty`（仓库×物料×批次）；且按业务时间重放无负库存 | 0 违例 |
| 成本链连续 | `cost_flow` 逐行 `balance_qty/balance_cost = 前行 + 本行 qty/amount`；`amount = qty×unit_cost` | 0 断链 |
| 凭证平衡 | 每张凭证 `total_debit = total_credit = Σ分录借方` | 0 不平 |
| 核销不超 | 应收/应付 `settled_amount ≤ amount`（红字负金额反向校验），状态 UNSETTLED/PARTIAL/SETTLED 自洽 | 0 超额 |
| 账户流水 | `balance_after` 自 500,000 连续滚动不透支 | 0 断链 |
| 计价口径 | 每物料移动加权=常量单价（采购价=ref_cost=成本流水单价），期末 `Σ成本数量 = Σ库存数量` | 0 差异 |
