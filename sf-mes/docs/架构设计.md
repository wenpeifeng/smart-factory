# MES 架构设计

> 结构与规范的唯一模板是 `../sf-erp`（同一套技术栈的 ERP 系统）。本文档只记录 MES 特有的架构决策；分层、REST、命名、注释、Git 规范见 `../sf-erp/docs/开发规范.md`，本文不重复。

## 1. 总体架构

模块化单体（Maven 多模块 + 聚合分组），单一部署单元 `mes-bootstrap`，前后端同仓：

```
mes-backend/          后端（包名 com.mes）
mes-web/              React 前端（三门户：业务 / admin 管理 / m 移动）
script/sql/migration/ Flyway 版本化脚本（以仓库根为工作目录启动）
```

依赖方向（单向，禁止循环）：

```
mes-common ← mes-framework ← mes-platform-{system,workflow,notify}
                                   ↓
              mes-biz-basedata ← {plan, execution, quality, material, trace,
                                  equipment, kanban, integration, report} ← mes-bootstrap
```

跨模块只调对方暴露的 Service 接口，不直接查别人的表。

## 2. 横切机制（mes-framework）

- **统一响应**：`Result<T>` / `PageResult<T>`；`pageNum/pageSize/keyword`。
- **安全**：Spring Security + JWT；默认全部接口需登录，白名单除外；`@RequirePerm` 按钮级权限（菜单/权限码存 sys_menu，前端 `HasPerm` 同码显隐）。
- **多租户 + 数据权限**：MyBatis-Plus 多租户插件（tenant_id 自动注入）+ `DataScopeInnerInterceptor` 五档数据权限（全部/本租户/本部门及以下/本部门/本人）。
- **单据规范组件**：Redis 单号生成器（前缀+yyyyMMdd+流水）、`@Idempotent` 幂等切面、`@OperLog` 操作日志切面、单据状态机（草稿→执行中→完工→关闭，支持红冲）。
- **审计**：每表 8 公共列（tenant_id/org_id/create_by/create_time/update_by/update_time/deleted/…）由 MP 自动填充；逻辑删除 `deleted`。
- **i18n**：中英双语消息（`i18n/messages*.properties`），`MesMessages` 静态门面。

## 3. 前端三门户（mes-web）

- `/` 业务门户 MainLayout：首页=车间工作台（待办工单/扫码报工入口/安灯）。
- `/admin/*` 管理门户 AdminLayout：用户/角色/菜单/部门/字典/日志/租户/通知通道，RequireAdmin 守卫。
- `/m/*` 移动门户：车间 PDA 扫码报工（过站报工/首检/安灯），独立轻页面，仅登录守卫。

请求层复用 erp-web 的 `request.ts`（axios 拦截器统一弹错/401 跳登录），列表页复用 PageTable 四件套（PageHeader/PageTable/StatusTag/HasPerm），路由表集中在 `router/index.tsx`，模块片段在 `router/modules/<模块>.tsx` 独立维护。

## 5. 分期路线

- **P1（已完成）**：平台（RBAC/租户/字典/日志/工作流/通知）+ 基础资料 + 前端骨架 + 一键启动 + 文档。
- **P2 执行核心**：integration 契约与 stub、plan 工单接收/齐套分析、execution 派工/过站扫码报工/WIP/完工回传、material 领退料+批次SN+标签打印、quality IQC/IPQC/OQC。
- **P3 深化**：trace 正反向追溯/电子批记录、SPC、equipment 台账/点检保养/OEE、kanban 安灯、排程甘特看板。
- **P4 呈现层**：车间电子看板、管理驾驶舱、报表中心、移动端报工完善、demo-data 演示剧本与演示账号。
