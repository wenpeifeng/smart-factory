> 一页看懂本系统。原理见《架构设计.md》《modules/*.md》，对接见《MES与ERP协同设计.md》与《modules/integration.md》，

## 1. 这是什么系统

自研 MES（制造执行系统），对标黑湖智造/鼎捷，定位**执行层**：排程、过站扫码报工、WIP、车间质检、追溯、领退料、OEE、看板。与 ERP（计划层，../sf-erp）、统一认证中心（../sf-auth）三系统三库分立部署、接口集成。P0~P4 全部交付并经真实三方联调。

身份体系：主账号生命周期只在 auth-center（建号/改密/离职在 sf-auth 操作）；MES 的 sys_user 是同步副本（employee_no 不可变工号为匹配键）。三层同步：手动按钮 + SSO 登录 JIT 建档 + 每小时全量对账（含孤儿禁用）。业务角色（报工员/质检员等）与菜单权限在 MES 管理端内部维护。

## 5. 核心业务流（已端到端验证）

```
ERP 下推生产订单/主数据 ──▶ /integration/erp/**（令牌鉴权，幂等落库）
  └─ 工单(DRAFT) ─下达▶ RELEASED（展开 BOM 用料 + 工艺工序）
        └─ 派工 ▶ 过站扫码报工（事务内：记录+WIP+工序/工单累计）
              ├─ PASS ─▶ 回传 ERP（完工报工/工单进度镜像，真实 http 已通）
              ├─ 领料审核 ─▶ 线边仓入库+回写工单已领+回传 ERP
              └─ 质检提交 ─▶ 汇总结论+SPC 采样判异+回传 ERP
追溯：领料/过站关键件 AFTER_COMMIT 落 trace_link ─▶ 正反向追溯 / EBR 电子批记录
```

## 6. 集成边界

- **auth-center**：OIDC 授权码+PKCE（JWKS RS256 验签）+ 用户同步（service API）+ 应用级启停；契约见 sf-auth/docs/业务系统接入指南.md
- **ERP**：六类接口双向 http（ERP 下推 4 + MES 回传 5 含进度镜像）；契约唯一事实源《MES与ERP协同设计.md》；可靠性 = int_push_log 幂等 + 5 分钟重试 + 对账页
- 三系统互不直连数据库（Integration Database 反模式）
