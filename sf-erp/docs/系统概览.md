# 系统概览（一页看懂 sf-erp）

> 对标金蝶 K3 / 用友 U8 的集团级 ERP：供应链 + 财务 + 生产 + 质量 + 成本 + 预算 + WMS。
> 本文是**速览入口**：系统是什么、跑在哪、有哪些能力、有哪些表、文档去哪找。
> 文档三层分工：**系统概览（本文，速览）→ 设计文档（原理）→ 接入/对接指南（操作）**。

## 1. 系统定位与部署拓扑

| 项 | 值 |
|---|---|
| 角色 | 集团 ERP（计划层）：主数据源头、MRP、供应链单据、库存/物料账、财务核算与报表 |
| 后端 | http://localhost:8080/api（Swagger：/swagger-ui.html） |
| 前端 | http://localhost:5173（业务门户）/ /admin（管理门户）/ /m（移动门户） |
| 数据库 | erp-mysql 容器：localhost:3306，库 `erp_db`，root/erp123456（**单库 + 表前缀分域**，无分库） |
| Redis | erp-redis 容器：6379，密码 erp123456 |
| 邻居系统 | sf-auth 统一认证中心（8082，SSO/用户同步）；sf-mes 制造执行（8081，生产订单下推/报工回传，见 docs/modules/mes-integration.md） |
| 一键启停 | ./script/sh/start-all.sh / stop-all.sh（连库停加 --with-db） |
| 演示账号 | erp_admin/123456（超管，套件统一命名）、zhanggm/Admin@123（总经理+审批待办）；SSO 统一登录入口在登录页 |
| 技术栈 | Java21 · SpringBoot 3.3 · MyBatis-Plus（多租户/数据权限拦截器）· Flyway(55 迁移) · React18+TS+AntD5 |

## 2. 能力总览（已交付，全部经真实联调/集成测试验证）

| 域 | 能力 |
|---|---|
| 系统平台 | RBAC(253 权限码)/租户(106 表 tenant_id)/字典/操作·登录日志/幂等/限流/打印中心(5 模板)/i18n 中英(768 key，异常消息全量 key 化) |
| 数据权限 | 五档（ALL/组织及下级/仅本组织/仅本部门/仅本人），拦截器零侵入注入；组织树递归 |
| 基础资料 | 物料/客商/仓库/计量单位/价格中心（成交价库·合同价·等级价·批量价·特价审批，四级定价引擎） |
| 采购 | 请购→询比价→比价定标→订单→入库→退货全链；暂估应付（货到票未到+发票冲回）；供应商准入(workflow 审批)+黑名单拦截+交易评分(A/B/C/D) |
| 销售 | 报价→下推订单→发货通知→出库→退货；信用管控；价格策略四级优先 |
| 库存/WMS | 统一 StockService（FIFO/批次/库位）；三级库区库位；任务引擎/波次；循环盘点 ABC；FEFO 效期；序列号；KPI |
| 质检 | IQC/IPQC/FQC 模板化检验；不合格处理；来料卡点（不合格拦截入库） |
| 财务 | 多账套；业务财务一体化（八类单据审核自动生成凭证，借贷平衡幂等）；会计期间结账/反结账；应收应付核销；三大报表（资产负债/利润/账龄，配置化映射）；预算 WARN-BLOCK 管控 |
| 成本 | 移动加权实际成本；工单成本归集；实时成本回写 |
| 计划/生产 | MPS/MRP（建议转采购/生产）；BOM（版本/替代料）；工艺路线；工单（三段式审批、直接领料/**倒冲领料**）；工序报工；批次追溯 |
| 资产/人事/设备 | 固定资产卡片折旧；HR 考勤计件工资；设备台账点检保养维修 |
| 集团组织 | 工厂树（总厂/苏州/东莞）；跨组织调拨与转移价格 |
| 审批流/通知 | 可配置三段式审批；钉钉/企微 webhook 通知+手机审批回写+预警群推 |
| 报表中心 | 8 组 14 张（收发存守恒/经营月报等） |
| **通用红冲+联查** | 6 类已审单据一键红冲（负数反向单+库存/往来反向）；单据全链上下游联查（报价→…→凭证） |
| **统一认证** | 接入 sf-auth：OIDC 授权码+PKCE SSO、JIT 登录建档、每小时全量对账（含孤儿禁用）、erp.admin↔超管 |
| **ERP↔MES 集成** | 六类接口双向（主数据/生产订单下推；报工/领退料/质检/进度回传），outbox 指数退避+幂等+集成监控页 |
