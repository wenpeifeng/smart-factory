## 踩坑清单（按严重度）

1. **Lombok 1.18.28 与 JDK 21.0.12 不兼容**（注解处理器 NoSuchFieldError 崩溃且报错位置误导）——父 pom 升 1.18.38。
2. **角色权限 Redis 缓存 10 分钟**（`auth:perms:{uid}`）：权限种子变更后必须 DEL 缓存或等过期，否则 403 排查半天。
3. **已应用的 Flyway 脚本再修改会 checksum 报错**：dev 环境手工 `UPDATE flyway_schema_history SET checksum=<新值>`，生产永远不改历史脚本。
4. **auth-center 令牌实际不带 iss claim**（其文档与实现有出入）：MES 侧验签 iss 放宽为"缺失跳过、存在须匹配"；aud 强校验。
5. **auth 离职/停用不触碰分配表 update_time** → `updatedSince` 增量同步必漏，对账一律全量。
6. **`Map.of().get(null)` 抛 NPE**（ImmutableCollections 特性）：所有按 id 查 Map 回填名称处必须先判空（Andon/Device/Workorder 均踩过）。
7. **MySQL NOT NULL 无默认值列**（如 plan_kit_check.result）：先插占位再回写最终值的模式需给占位值。
8. **空集合传 selectBatchIds 生成 `IN ()` SQL 语法错误**：批量查询前判空。
9. **BigDecimal.divide 不带 scale** 非整除抛异常（SPC 中心线计算静默失败）。
10. **bash 脚本里 `$VAR` 后紧跟全角字符**会被当作变量名一部分（非 UTF-8 locale），一律 `${VAR}`。
11. **docker exec mysql 输出中文乱码**：加 `--default-character-set=utf8mb4`。
12. **mes-web redirect_uri 注册**：auth 侧 app_client 必须是 `http://localhost:5173/sso/callback`（SPA 回调），种子曾误注册 8081。
13. service/管理端 token 两套体系（auth HS256 管理 / RS256 OIDC）勿混用；MES 出站令牌=ERP 入站令牌=erp-integration-token。
